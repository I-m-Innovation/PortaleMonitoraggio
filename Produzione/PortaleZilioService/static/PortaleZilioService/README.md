Static assets for PortaleZilioService app.
- css/: stylesheets
- js/: scripts
- images/: images/icons
- fonts/: local fonts
- vendor/: third-party static assets

Notes:
- `.gitkeep` is a placeholder file used to keep otherwise-empty folders tracked by Git.
- `vendor/` is for third-party frontend assets stored locally (for example Bootstrap/Chart.js files, plugins, icon packs, or external fonts).
- If a folder is no longer empty, `.gitkeep` can be removed.
